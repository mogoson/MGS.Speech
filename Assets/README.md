# MGS.Speech

## Summary

- Speech recognize on Windows platform.

## Ability

- Keyword recognize.
- Dictation recognize.

## Platform

- Windows (PC, HoloLens 2)

## Network

- Online
- Offline

## Install

- Unity --> Window --> Package Manager --> "+" --> Add package from git URL...

  ```text
  https://github.com/mogoson/MGS.Speech.git?path=/Assets
  ```

## Samples

- Unity --> Window --> Package Manager --> Packages-Mogoson --> Speech --> Samples.
